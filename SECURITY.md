# Security policy

This is a learning and portfolio project. It has had no independent security review. Do not rely on it as your only protection.

* Found a problem? Open a private report to the repository owner rather than a public issue, and include the smallest input that shows it. Do not include real secrets or personal data.
* Never commit keys, `.env`, audit logs or `*.db`. If you pasted a real key anywhere, replace it.
* What the project does and does not protect against: `docs/security.md`. Measured results: `docs/final_report.md`.
